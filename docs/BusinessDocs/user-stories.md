# User Stories: aQua Lifestyle Club Platform

Checked items are supported by the current codebase; unchecked items are gaps.

## Epic 1: Membership Management
- [x] As an admin, I want to create memberships with a tier (Jasper, Onyx, AQGreen, Business Premier) so members are classified correctly
- [x] As an admin, I want to set a membership activation date so benefits start from the right time
- [x] As an admin, I want to track and mark monthly obligations so tier compliance is enforced
- [ ] As a prospect, I want to activate a Jasper Standard (R950) or Premium (R1200) plan so I receive my combo allocation and membership access
- [ ] As an Onyx member, I want to subscribe at my qualified IBA level (1–5) so I receive the correct monthly order volume
- [ ] As an Onyx member, I want a virtual membership card with a QR code so I can be identified at any Area Space
- [ ] As an admin, I want to see members who have not committed fully within 4 months so I can follow up

## Epic 2: AQGreen Savings Club
- [ ] As a member, I want to open a club savings account (Standard / Club Millionaire / Business Premier / Investment) so I can save monthly
- [ ] As a member, I want to deposit savings between the 1st and 15th so my payment is accepted
- [ ] As a member, I want to be prevented from depositing between the 17th and 24th so I comply with the admin verification window
- [ ] As a member, I want to see my accrued 20% interest/share pool so I can track growth
- [ ] As an admin, I want members below the minimum savings threshold within 3 months to be flagged for refund (minus admin/branding) so the refund rule is enforced
- [ ] As an admin, I want to verify proof of payment against deposits so records are accurate

## Epic 3: Products & Orders
- [x] As an admin, I want to manage products (create, list, view) so the catalog stays current
- [x] As a member, I want to see only products my membership tier is eligible for so pricing/access rules are respected
- [x] As a member, I want to create an order intent and have it reserved, completed, or cancelled so my monthly order is tracked
- [ ] As a Jasper member, I want to order monthly combos (Combo 2/3/4/5) at Jasper pricing so I maintain my plan
- [ ] As an Onyx member, I want my monthly level order (Combo 4 ×1/×4/×8) generated automatically so I meet my subscription
- [ ] As a member, I want orders accepted only within the opening/cut-off windows so delivery dates are honored
- [ ] As a member, I want an SMS/notification when my order is released for collection so I collect on time
- [ ] As an admin, I want to confirm proof of payment before releasing orders so no unpaid stock leaves

## Epic 4: Registration & Enquiries
- [x] As a prospect, I want to submit an enquiry so the club can contact me
- [x] As an admin, I want to respond to, close, and reopen enquiries so the pipeline stays organized
- [x] As an admin, I want to record follow-ups with outcomes so conversion probability is estimated
- [x] As an admin, I want to convert an enquiry into a customer so sign-ups are seamless
- [x] As an admin, I want to assign enquiries to members so ownership is clear
- [ ] As a prospect, I want to register online (WhatsApp/admin), at the office, or at a presentation so I can join through any channel
- [ ] As a prospect, I want to submit my ID, contact info, and bank confirmation letter so my registration is complete
- [ ] As a registrant, I want SMS confirmations of payment, welcome, and collection dates so I know my status

## Epic 5: Area Leaders & Area Spaces
- [ ] As an Onyx member, I want to apply for an Area Leader license once 20+ people in my area are interested so I can run an Area Space
- [ ] As an applicant, I want to submit my profile (photo, ID, address, social media, agreement, startup stock) so my application can be reviewed
- [ ] As an admin, I want to review Area Space applications (42h review, 4 consecutive presentations) so only qualified areas are approved
- [ ] As an Area Leader, I want to progress through ranks (Ruby → Ambassador) based on order volume so my income and benefits grow
- [ ] As an Area Leader, I want to place orders on behalf of my members so collections are consolidated
- [ ] As an Area Leader, I want to submit weekly Area Space reports so the head office tracks growth
- [ ] As an admin, I want to enforce the 300-Area-Leader cap so licensing stays controlled

## Epic 6: Facilitators & Referrals
- [ ] As a member, I want to register as a Facilitator so I can promote aQua and earn incentives
- [ ] As a Facilitator, I want my direct and indirect referrals tracked so I progress through ranks (Bronze → Premier T/60)
- [ ] As a Facilitator, I want to receive awards/incentives when I complete a stage so my work is rewarded
- [ ] As a Facilitator, I want to rate Area Leader service and report misconduct so quality is maintained
- [ ] As a Facilitator, I want to redirect new members to their nearest Area Space so they are onboarded properly

## Epic 7: Business Premier & Investments
- [ ] As a Business Premier member, I want to join a clubbing plan (A–D) so my business can access pooled equipment purchases
- [ ] As a Business Premier member, I want to borrow after 6 months of unbroken saving so I can fund business initiatives
- [ ] As a member, I want to participate in the 40% liquidity share pool so I receive bi-quarterly profit distributions
- [ ] As a Club Millionaire member, I want my funeral plan auto-linked (R30,000, 6-month wait) so my family is covered

## Epic 8: Therapy, Training & Events
- [ ] As a member, I want to book Life Therapy packages via my Area Leader or admin so I access wellness services
- [ ] As a member, I want to see the training/events calendar so I attend the right sessions
- [ ] As an admin, I want to record training attendance so Facilitator obligations are tracked

## Epic 9: Platform Administration
- [x] As an admin, I want to manage users and roles so access is controlled
- [x] As an admin, I want to manage tenants so club divisions are isolated
- [x] As an admin, I want a web UI for customers, products, memberships, enquiries, and order intents so daily operations are efficient
