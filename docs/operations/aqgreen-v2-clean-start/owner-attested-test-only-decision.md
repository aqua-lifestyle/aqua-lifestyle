Authority is the owner's current, explicit instruction: “This is my formal
business-owner classification.” The owner classifies the existing AQGreen cohort
as test activity and directs a clean start while preserving financial records and
historical obligations. This is owner attestation, not independent verification
of provider mode, settlement or absence of bank claims. It is not final

`providerModeVerification: NOT_INDEPENDENTLY_VERIFIED`. Existing payment evidence
